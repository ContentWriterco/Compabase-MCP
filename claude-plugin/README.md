# Compabase plugin for Claude

Polish company data in Claude: 3M+ companies from the KRS and CEIDG registers with financial statements, owners, public tenders and risk checks.

- MCP server: `https://compabase.com/api/mcp/claude` (sign in with your Compabase account via OAuth)
- Skill: `compabase-company-research` (recommended workflow for company research)
- Docs: https://compabase.com/docs/mcp/
- Privacy: https://compabase.com/privacy

Install in Claude Code:

```
/plugin marketplace add ContentWriterco/Compabase-MCP
/plugin install compabase@compabase-plugins
```
